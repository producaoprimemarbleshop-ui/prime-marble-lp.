# Prime Marble Shop LP

Site estatico recriado a partir do pacote Unbounce `_prd_prime_marble_shop_lp_g.unbounce`.

## Rodar localmente

```powershell
python -m http.server 4173
```

Depois abra `http://localhost:4173`.

## Deploy no Render

1. Suba esta pasta para um repositorio GitHub.
2. No Render, crie um Static Site apontando para o repositorio.
3. Configure `Publish Directory` como `.`.
4. Adicione o dominio customizado `lp.primemarbleshop.com`.
5. Ajuste o DNS conforme o valor indicado pelo Render.

O site mantem GTM `GTM-TQSTHBSN`, Clarity `qem0ys2f7n`, WhatsApp, Instagram e Google Maps da LP original.
